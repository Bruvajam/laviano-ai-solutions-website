# Laviano AI Solutions — Website

Standalone marketing site for **Laviano AI Solutions** (AI receptionist).

## Open the site

Double-click `Laviano AI Solutions.html`, or open it in any browser.

Local preview (optional):

```powershell
powershell -ExecutionPolicy Bypass -File ._serve.ps1
```

Then visit `http://127.0.0.1:8765/`

## Files

| File | What it is |
| --- | --- |
| `Laviano AI Solutions.html` | **Live site** — use this one |
| `Laviano AI Solutions (standalone).html` | Original Claude Design export |
| `Laviano AI Solutions (standalone) - BACKUP.html` | Safety copy of the original export |
| `_serve.ps1` | Local preview server |

## Restore later

Clone this repository and open `Laviano AI Solutions.html`. That file is the full website (HTML, CSS, and JavaScript in one document).
